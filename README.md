- **Full-Stack Tech Stack**: Built with **FastAPI**, **Scikit-Learn**, **Google Gemini API**, **React 19**, **TypeScript**, **Tailwind CSS**, and **SQLite/SQLAlchemy**, deployed on **Render**.
